# Zylo Phase 9: AI Nudges Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Zylo AI notices when the room goes quiet or the chat stalls, and may post one short nudge into ZyloChat, captioned with why it spoke. Nudges are off by default and the host turns "AI nudges" on per meeting. The AI decides whether to speak at all (`NO_NUDGE`); nothing canned is ever posted.

**Architecture:** The pure rules live in `server/lib/nudge.js`: stuck phrases, "going in circles", the quiet rule, the prompt and the `NO_NUDGE` decision. The signals live in the room's Redis meta hash. A browser reports "my person spoke" as `voice:activity`, at most once every 10 s and only while nudges are on. Every relayed person's chat line stamps `lastChatAt`. Switching nudges on stamps `nudgesOnAt`. The chat triggers run after a `chat:message` is relayed, and the quiet check runs in every server's existing 15 s sweep. A Redis claim (`SET … NX PX 90000`) lets exactly one server fire. It asks Phase 8's provider client for the whole answer (not streamed), re-checks, and posts `ai:nudge` to the room. On the web, the Phase 8 reducer adds the nudge as a finished, captioned Zylo AI item. Phase 8's pop-up and live region already handle finished AI items, so they need no change.

**Tech Stack:** Node 22 (global `fetch`, `AbortSignal`), Express 5, Socket.IO 4.8 + Redis adapter, ioredis 5 (Lua scripts), Postgres 16, node:test; web: Next.js 16, React 19, Tailwind v4, shadcn/Radix, livekit-client 2, sonner.

**Spec:** `docs/superpowers/specs/2026-10-04-zylo-phase-9-nudges-design.md` (binding; this plan argues from it).

## Decisions this plan makes where the spec is open

1. **`promptFor(history, question = null)`.** The spec wants Phase 8's transcript "with no question line", but `promptFor` always appends the question. This plan makes the question optional, which is a one-line change to `ai.js` beside the `stream` change spec §10 names. Ask AI's call is unchanged.
2. **Where "effectively on" is decided for `voice:activity`.** `use-meeting.ts` owns the throttle (`shouldReportSpeech`) and the emit (`reportSpeech`). The gate (`aiNudges && aiEnabled && aiAvailable && !translator`) lives in `meeting-room-flow.tsx`, which alone holds the card's `aiAvailable` and mode. It hands `reportSpeech` to `useLiveKitRoom` only while nudges are on. The net effect matches spec §7: the browser emits only while nudges are effectively on.
3. **The pop-up and the screen-reader announcement need no new code.** `room-shell.tsx`'s `newlyDone` and `chat-panel.tsx`'s live region already act on any `kind: 'ai'` item with `status: 'done'`, and a nudge is exactly that. Task 5 tests that `newlyDone` hands a nudge out once. `room-shell.tsx` only passes the new setting through.
4. **Caption placement.** "With the caption above it" is read as inside the indigo bubble, between the `Zylo AI` name line and the nudge text, at the timestamp's `opacity-70` (`text-muted-foreground` is unreadable on indigo, as Phase 8 found for `--destructive`).
5. **`host:set-nudges { enabled: true }` stamps `nudgesOnAt` before writing `aiNudges = '1'`.** That way a sweep between the two writes never sees nudges on with an old clock. It does not clear `quietNudged`; the spec clears that only on speech or chat.
6. **"Logged once per outage"** for signal writes uses a flag that the next success resets, the same pattern as `runSweep`'s `sweepFailing`.
7. **The 3-word minimum** counts words including repeats. The overlap uses word sets.
8. **A line's circles check reads the history after that line is remembered.** If two lines land at the same moment, the earlier line's check may already see the later one. This is harmless: at worst the earlier check fires the nudge the later one would have fired, and the claim still allows one. The tests settle between lines so each check sees exactly what it should.
9. **One person talking without pause.** `ActiveSpeakersChanged` fires on changes, so a long monologue might never re-report and a quiet nudge could interrupt it. The browser therefore polls `room.localParticipant.isSpeaking` every 2 s (spec §2 and §7 amended to match); `use-meeting` still throttles to one report per 10 s.

```js
// Zylo AI nudges: when the AI may speak up unasked, and what it is told then. Pure
// rules with no I/O, so they're tested alone; room.js reads the signals, claims the
// nudge, asks the AI and posts what it says.

const QUIET_MS = 60_000;
const MIN_SEATED = 2;
const MIN_HUMAN_LINES = 2;
const CIRCLE_LINES = 3;
const CIRCLE_MIN_WORDS = 3;
const CIRCLE_OVERLAP = 0.6;

// Lower case, curly apostrophes straightened, whitespace runs collapsed to one space.
const normal = (text) =>
  text
    .toLowerCase()
    .replace(/[‘’]/g, "'")
    .replace(/\s+/g, ' ')
    .trim();

// English only. Whole words, so "stuckey" or "I know" never match.
const STUCK_PHRASE = /\b(?:i'?m stuck|we'?re stuck|i don'?t know|idk|no idea|not sure|i'?m lost)\b/;
// A whole line of "??" (or more), or of "hm", "hmm", "hmmm"...
const STUCK_LINE = /^(?:\?{2,}|hm+)$/;

// Someone just wrote that they are stuck or unsure.
function stuckPhrase(text) {
  const line = normal(text);
  return STUCK_PHRASE.test(line) || STUCK_LINE.test(line);
}

// Lower-cased words, punctuation stripped.
const wordsOf = (text) => normal(text).replace(/[^\p{L}\p{N} ]/gu, ' ').split(' ').filter(Boolean);

// Jaccard: the words two lines share, over all the words either uses.
function overlap(a, b) {
  const shared = [...a].filter((word) => b.has(word)).length;
  return shared / (a.size + b.size - shared);
}

// lines: what people wrote, oldest first. The last 3 repeat one point: each has at least
// 3 words, and every pair shares more than 60% of their words.
function goingInCircles(lines) {
  if (lines.length < CIRCLE_LINES) return false;
  const words = lines.slice(-CIRCLE_LINES).map(wordsOf);
  if (words.some((w) => w.length < CIRCLE_MIN_WORDS)) return false;
  const sets = words.map((w) => new Set(w));
  return sets.every((a, i) => sets.slice(i + 1).every((b) => overlap(a, b) > CIRCLE_OVERLAP));
}

// The cheap half of the quiet rule, the meta alone: no quiet nudge yet in this stretch,
// and a minute since the last speech, chat line or nudges being switched on (missing
// times read 0). room.js asks this before it reads the seats and the history.
function quietLongEnough(meta, now) {
  return !meta.quietNudged && now - Math.max(meta.lastVoiceAt, meta.lastChatAt, meta.nudgesOnAt) >= QUIET_MS;
}

// The quiet-room trigger: quiet long enough, at least 2 people seated, and at least 2
// lines from people for the AI to read (it only sees the chat).
function isQuiet(meta, now, seated, humanLines) {
  return quietLongEnough(meta, now) && seated >= MIN_SEATED && humanLines >= MIN_HUMAN_LINES;
}

const REASONS = {
  quiet: 'nobody has spoken or typed for a minute',
  stuck: 'someone just wrote that they are stuck or unsure',
  circles: 'the last few chat messages repeat the same point',
};

// The system prompt for a nudge (spec §5, verbatim apart from the reason clause).
const NUDGE_PROMPT = (reason) =>
  [
    'You are Zylo AI, a shared assistant inside a live video meeting.',
    `Nobody asked you anything: you are speaking up because ${REASONS[reason]}.`,
```

```js
async function quietForAMinute(store, meetingId) {

// Wraps a fake provider's respond: `asked` settles when a request arrives. With hold, the
// answer waits for release(), so a test can act while the AI is "thinking".
function watchProvider(respond, { hold = false } = {}) {
  let arrived;
  let release;
  const asked = new Promise((resolve) => {
    arrived = resolve;
  });
  const released = hold ? new Promise((resolve) => (release = resolve)) : null;
  return {
    asked,
    release: () => release(),
    respond: async (res, request) => {
      arrived();
      await released;
      await respond(res, request);
    },
  };
}

// Refuses one policy and records every take.
function refusingLimiter(policy) {
  const takes = [];
  return {
    takes,
    take: async (name, id) => {
      takes.push([name, id]);
      return { allowed: name !== policy, remaining: 0, retryAfterMs: 10_000 };
    },
  };
}
```

```js
  // Nudges are effectively on: the host's setting, AI in chat, an AI client on this
  // server, and not a Translator Convo. Otherwise nothing is checked beyond the meta.
  const nudgesOn = (meta) => Boolean(ai && meta && meta.aiNudges && meta.aiEnabled && meta.mode !== 'translator');

  // One nudge: claim it (one server, once per 90 s per meeting), spend the deployment's
  // budget, ask the AI with the last 20 chat lines, re-check, then post. Never a canned
  // line: silence, an empty answer or any failure posts nothing.
  async function nudge(meetingId, reason) {
    if (!(await store.claimNudge(meetingId))) return; // another server has it, or the cooldown runs
    if (reason === 'quiet') await store.setMetaField(meetingId, 'quietNudged', '1'); // one claim per quiet stretch
    if (!(await limiter.take('aiNudgeAll', 'all')).allowed) return;
    const answer = await ai.stream({
      messages: promptFor(await history.recent(meetingId)),
      system: NUDGE_PROMPT(reason),
      maxTokens: NUDGE_MAX_TOKENS,
      signal: answers.signal,
    });
    const text = nudgeText(answer);
    if (!text) return;
    // The meeting may have ended, or the host switched nudges or AI off, while it thought.
    if (!nudgesOn(await store.getMeta(meetingId))) return;
    io.to(roomChannel(meetingId)).emit('ai:nudge', { id: randomUUID(), text, reason, ts: Date.now() });

  }

  // Runs a nudge without making the caller (the chat handler, the sweep) wait for the
  // provider; failures are logged on the server only.
  const fire = (meetingId, reason) =>
    nudge(meetingId, reason).catch((err) => console.error('AI nudge failed:', err.message));

  // The chat triggers, after a person's line was relayed and remembered (never an Ask AI
  // line: the AI is already answering that one). A stuck phrase wins over circles.
  async function checkChat(meetingId, text) {
    if (!nudgesOn(await store.getMeta(meetingId))) return;
    let reason = stuckPhrase(text) ? 'stuck' : null;
    if (!reason) {
      const lines = (await history.recent(meetingId)).filter((entry) => !entry.ai).map((entry) => entry.text);

    }
    if (reason) fire(meetingId, reason);
  }
```
